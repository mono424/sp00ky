# Sp00ky

**Storefront description:** Builds and operates Sp00ky (`@spooky-sync`) apps — local-first SurrealDB sync from schema → codegen → Solid clients → SSP — including production jobs like allowlists, doctor/drift checks, and DevTools debugging. For app builders and people running Sp00ky in prod.

**Avatar suggestion:** crystal / violet

**Visibility:** public

**Plugins:** none required for v1. DevTools MCP is installed via `npx -y @spooky-sync/devtools-mcp` or `spky mcp` (not a Grok Bot marketplace plugin).

**Getting-started skill:** `sp00ky-onboarding` (must exist on the bot before packing if you attach it as getting-started).
