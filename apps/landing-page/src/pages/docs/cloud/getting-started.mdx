Sp00ky Cloud handles infrastructure provisioning, scaling, and management so you can deploy your project with a single command. No Docker Compose files, no server setup, just `spky deploy`.

## Prerequisites

- The Sp00ky CLI installed (`pnpm add -D @spooky-sync/cli` per project, or `npm i -g @spooky-sync/cli` globally)
- A `sp00ky.yml` config file in your project root
- Docker installed locally (for building backend images)

Once it is up, `spky status` lists your endpoints. One of them is
`https://<slug>-admin.<domain>/admin`, the
[operator dashboard](/docs/reference/admin-dashboard): cluster health, live logs,
workflow runs and the restart and backup actions, in a browser. Grant yourself

empty.

## Destroying a Project

<Warning>
Destroying a project deletes everything it has, for good: its containers or Workers, its database and the volumes behind it, and its backups too. Nothing is kept to restore from. To keep the data, export it first with `surreal export`, using the login `spky project credentials` prints.
</Warning>
