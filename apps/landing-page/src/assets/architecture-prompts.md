## Architecture walkthrough layers (2026-09-13)

Generated with the built-in image generation tool. Each module is a separate image, consumed by `SyncArchitecture.astro`. Actual SurrealDB and sp00ky 00 logo assets are projected onto the image surfaces in HTML/CSS; Solid, Flutter and Rust marks use the installed Simple Icons package. Logo artwork is not model-generated.
