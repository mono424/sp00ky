<Note>
  Starting fresh? [`spky init`](/docs/quickstart) scaffolds the project, installs everything and
  generates types in one go. This page is for adding Sp00ky to an existing codebase.
</Note>

**Requirements:** Node.js 22.12 or newer (the workspace pins `>=22.21.1`), and Docker for the local
stack. Rust only if you intend to build the SSP or scheduler from source, prebuilt images are the
default.

<Steps>
  <Step title="Install the CLI">
    <CodeBlock code={cliCode} lang="bash" />

    `spky` is how you generate types, run migrations, start the local stack and deploy.
  </Step>

  <Step title="Install the client SDKs">
    The core client plus the bindings for your framework.

    <CodeBlock code={sdkCode} lang="bash" />

    Flutter projects depend on `spooky_core` (and `spooky_flutter` for
    widgets such as `BucketImage`) instead. See the
    [Flutter guide](/docs/guide/flutter). Apps on the Solid 2.0 RC install
    `@spooky-sync/client-solid2` instead of `client-solid` — see the
    [Solid 2 guide](/docs/guide/solid2).
  </Step>

  <Step title="Start the stack">
    <CodeBlock code={devCode} lang="bash" />

    This brings up SurrealDB and the SSP sidecar, applies migrations, and starts any app with a
    `dev` block in `sp00ky.yml`. See [spky dev](/docs/dev).

    If you'd rather wire the infrastructure yourself:

    <CodeBlock fileName="docker-compose.yml" code={composeCode} lang="yaml" />

    <CodeBlock code={composeUpCode} lang="bash" />
  </Step>

  <Step title="Verify">
    <CodeBlock code={doctorCode} lang="bash" />

    `spky doctor` checks that `sp00ky.yml` parses, the schema source exists, generated types are
    current, and the migrations directory is in place. Each failed check prints the command that
    fixes it. Re-run it after every schema edit. It's the fastest feedback loop there is.
  </Step>
</Steps>

export const cliCode = `pnpm add -D @spooky-sync/cli`;

export const sdkCode = `pnpm add @spooky-sync/core @spooky-sync/client-solid`;

export const devCode = `spky dev`;

export const composeCode = `services:
  surrealdb:
    image: surrealdb/surrealdb:v3.1.0-beta.3
    command: start --user root --pass root rocksdb:/data/db
    ports:
      - "8666:8000"
    volumes:
      - ./data:/data

  ssp:
    image: ghcr.io/sp00ky-org/ssp-server:canary
    environment:
      - SPKY_DB_URL=http://surrealdb:8000
      - SPKY_DB_USER=root
      - SPKY_DB_PASS=root
      - SPKY_SSP_LISTEN_ADDR=0.0.0.0:8667
      - SPKY_SSP_REF_MODE=dedicated
    depends_on:
      - surrealdb`;

export const composeUpCode = `docker compose up -d`;

export const doctorCode = `spky doctor`;
