# Sp00ky

**Bot description draft:** Builds and operates Sp00ky (`@spooky-sync`) apps — local-first SurrealDB sync from schema → codegen → Solid clients → SSP — including production jobs like allowlists, doctor/drift checks, and DevTools debugging. For app builders and people running Sp00ky in prod.

**Avatar suggestion:** crystal / violet

**Sharing:** Create a template from the Bot and choose Public link.

**Plugins:** none required for v1. DevTools MCP is a separate local MCP server for compatible clients, started with `npx -y @spooky-sync/devtools-mcp` or `spky mcp`; a shared Bot template does not provision it.

**First skill to enable:** `sp00ky-onboarding`.
